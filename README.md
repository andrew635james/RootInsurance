# Root Insurance

## Description
Root Insurance is a modern web application designed to simplify expense tracking and receipt management for insurance‑related workflows. The project provides a clean interface for users to log expenses, upload receipts, and generate summaries that can be used for claims or audits. Built with scalability in mind, it leverages React for dynamic UI rendering and ensures smooth integration with backend services. The goal is to empower users with transparency and efficiency in managing insurance‑related financial data. With intuitive forms, lists, and reporting features, Root Insurance reduces manual effort and enhances accuracy. This repository serves as a foundation for developers to extend functionality, integrate APIs, and customize workflows for diverse insurance use cases. Contributions are encouraged to improve usability, add new features, and maintain high coding standards.

## Features
- Expense logging with form validation  
- Receipt upload and preview  
- Dynamic expense list with filtering  
- Responsive header navigation  
- Claim‑ready reporting tools  

## Technologies Used
- React.js  
- CSS3  
- HTML5  
- Node.js
